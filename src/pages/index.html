I am a Ph.D. candidate in Computer Science at the University of Virginia, advised by Dr. Ashish Venkat, working on memory compartmentalization and privilege isolation. My research uses compiler infrastructure to split software into isolated compartments, enforce fine-grained access policies between them, and verify that those policies hold, so that a compromise in one part of a program cannot reach memory or privileges it was never meant to have.

In my current work, I build LLVM passes that automate compartmentalization from program annotations, verify policy correctness across a multi-stage pipeline, compress access matrices to keep enforcement lean, and guide where hardware-enforced gate calls are placed.my thesis, roughly

Isolation is only practical if its cost is acceptable. As a Ph.D. intern at Google, I optimized large-scale, high-performance cloud workloads, reasoning about hardware constraints and multi-objective tradeoffs. That experience shapes how I approach the performance side of isolation: domain crossings, metadata size, and where enforcement overhead actually lands on real hardware.

My earlier work includes object-level memory profiling of Chromium (SIGMETRICS 2026) and a background in threat intelligence, malware analysis, and reverse engineering, which informs how I think about attackers moving through a system.how it started
